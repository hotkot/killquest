KILLQUEST — WINDOWS x64 PORTABLE BUILD (v56)

1. Extract the entire ZIP to a folder.
2. Double-click KillQuest.exe. Keep it beside its resources and DLL files.
No internet connection or separate runtime installation is needed.

F11 toggles fullscreen. Alt+F4 closes the app.
WASD/arrows move; J light/pickup/grab, K heavy, L dodge, Space jump, I rage.
Xbox/PS5 controllers use the existing in-game mappings. A/X on a second
controller joins player 2 in character selection. Click inside the game,
then press a controller button. Options controls music/effects volume.
Audio options save to the local Windows user profile.

Includes v55 controller menu highlighting and the v54 fixes: grounded Lyra pickup poses and rebalanced
120-second thrash-metal menu music.

This build is unsigned. It was cross-packaged on Linux; Windows launch
and physical controller behavior have not been tested in this environment.
Electron and Chromium third-party licenses are included in the package.

SCORING: dagger 100, sword 150, archer 150, dog 125, bruiser 300.
Points go to the finishing player or throw/pit owner. Death subtracts
up to 200 points, with a minimum of zero. The end screen shows each
player separately. Restart starts a new score.
