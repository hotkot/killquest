KILLQUEST — WINDOWS x64 PORTABLE GAME

Extract the entire ZIP, then double-click KillQuest.exe.
Keep the EXE beside its resources, DLLs and license files.
No internet connection, Python or Node.js is needed to play the packaged game.
Requires a Windows version supported by Electron 45 (Windows 10 or newer, x64).

F11 toggles fullscreen. Alt+F4 closes the game.
WASD/arrows move; J light/pickup/grab, K heavy, L dodge, Space jump, I rage.
Up to four local players with distinct heroes are supported. Additional standard
controllers join character selection with A/Cross. Click/focus the game and
provide an input gesture for audio/gamepad activation.
Audio options save to the Windows user profile.

This package is unsigned. Automated checks do not replace Windows gameplay,
audio, display and physical-controller testing. Electron/Chromium licenses and
the game's audio credits remain included. Continue/campaign saves and the City
boss are not implemented; future regions remain locked.
