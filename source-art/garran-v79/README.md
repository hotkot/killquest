# Garran raised arc / grounded spin / preserved stab

Built-in image generation created two full 16-frame strips from approved Garran references. The first prompt specifies a circular overhead cut with successive raised, upright, up-right, level, down-right, and downward sword angles, starting raised and ending low. The second specifies a single grounded 360-degree turn with right, rear, back, left, front, and right views, one sword and one forearm shield, followed by chambering for the existing stab. Both prompts require four columns by four rows, transparent background, fixed body scale and full weapon padding. The spin's intermediate left-facing poses were refined in a complete-strip correction.

`python scripts/normalize_garran_v79.py` reproduces the runtime PNGs with shared strip scales, centered bodies, fixed boot baselines, and roomy 640×448 canvases. Downward-cut source frames 2, 3, 1 are ordered first so the blade starts upright then descends instead of lifting again. Final low follow-through stays low. Boots, rather than the blade tip below them, establish the cut's ground pivot. The spin begins from that low finish and ends on the unchanged stab's chamber pose.

All twelve stab PNGs are deliberately untouched. Their SHA-256 values are recorded in `preserved-stab-sha256.json` and checked in `checks/sprites.py`. Runtime timings show all 44 combo frames and apply three separate hits at their contact poses. Browser playtesting was unavailable; source image review, sprite integrity, scene resource/lifecycle, and combat simulation checks were used.

Reviewed corrections: the second spin source mistakenly started another turn in its recovery row. Those two poses are omitted and clean chamber poses are held instead, keeping exactly one rotation. The first spin pass is retained as unused source history. The first slash intentionally does not lock its raised start back to idle. Frame selection, source ordering, and shared scales are recorded in `registration.json`.
