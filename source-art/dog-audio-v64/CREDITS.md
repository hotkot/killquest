# Canine audio sources

- Dog sounds by pauliuw: https://opengameart.org/content/dog-sounds — CC0, https://creativecommons.org/publicdomain/zero/1.0/ . Original dog.7z preserved. Selected real bark/whine recordings are normalized, filtered, cropped, faded and modestly pitch varied for game playback.
- Dog Growl by bonebrah: https://opengameart.org/content/dog-growl — CC0, same license. Original growl.ogg preserved. Filtered, normalized, faded and slightly pitch varied.
- Bite contact layers derive from the game's existing flesh effect library, shortened and softened.

Run scripts/prepare_dog_audio_v64.py with ffmpeg installed to recreate all eleven runtime WAV files in dist/assets/audio.
