# Active rebel combat v156

Rebels run the same soldier AI as the royal forces through an isolated faction context: shared movement, formations, shield-line advancement/reassembly/reversal, target selection, melee ranges/cooldowns, spears, crossbow firing/reloading, knight combos/parry and rear parry cancellation. Hostiles can target heroes or rebels; rebel targets and bolts only hit hostile NPCs. Friendly NPCs remain independent on the current screen and walk to catch up only when the screen moves away (updated in v157); they do not steer toward hero-relative positions. Both sides take damage, get thrown/knocked down and die. Knight elites retain stagger immunity. Repeated NPC-versus-NPC shield blocks briefly wear down a guard to prevent an endless frontal stalemate; player guard interactions retain their existing rules. NPC kills/fall damage do not award hero score, rage or combo credit.

Art: 120 combat texture slots under dist/assets/characters/rebel-{role}-combat-00.png through -23.png, in addition to the existing idle strips. Raw sheets in this folder. Built-in imagegen identity-preserve mode, using approved rebel idle sheets as identity/style references. One full sheet per role; a smaller replacement knight action sheet avoids overlapping source weapons. Bulwark full-thrust poses are held across contact frames; spear windup uses forward-facing ready poses; the fired crossbow bolt is rendered by the projectile system, not duplicated in the sprite. Shared scale per animation family and foot y408; 768x448 frames, 1024x448 for spear clearance. Existing measured in-level scales retained.

Normalize: scripts/normalize_rebel_combat_v156.py. Native visual QA: checks/render-rebel-combat-v156.cjs produces battle-preview.png from an actual combat simulation and pose-preview.png. Source poses with merged neighbors were rejected rather than included in game frames.
