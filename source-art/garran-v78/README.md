# Garran: downward slash → horizontal slash → stab

Three dedicated twelve-frame transparent strips replace the eight-frame slash/stab/finisher sets. All use the shipped Garran idle as their identity reference. Source edit canvas was produced with the Game Studio sprite pipeline helper. Built-in image generation was used.

Prompt set: preserve the same closed-helmet knight, red plume/cape, white sun tabard, single straight one-handed sword and single forearm-strapped wooden-backed shield; face right throughout. Exactly twelve full-body poses per strip, four columns by three rows, transparent background, fixed proportions/camera, no effects or duplicate weapons. First strip: overhead windup into a downward cut and low follow-through. Second: load from low guard and sweep horizontally before chambering the sword at the hip. Third: extend straight forward for a stab, then withdraw to low ready. Frame seven is each strike's contact pose.

Reproduce final PNGs with `python scripts/normalize_garran_v78.py`. It uses one shared scale per source strip, measures plume-to-feet rather than sword height, registers the torso at x=320 and the planted foot at y=408, and preserves a 640×448 canvas so extended blades stay visible. Exact endpoint poses connect all three actions and the return to idle. The runtime preloads all twelve poses and uses contact frames for damage timing. Preview sheet contains final game assets.

The first horizontal pass was rejected because the follow-through resembled a jab. The corrected `cross.png` explicitly keeps the elbow bent during the sweep, follows through with the right arm across the chest and the blade pointing left in frames 8–10, then chambers at the right hip for the final stab. The first pass is retained only as source history and is not shipped. All final frames passed silhouette connectivity, ground registration, transparent-padding, frame reachability, contact timing, and endpoint seam checks. Browser QA was unavailable in this environment.
